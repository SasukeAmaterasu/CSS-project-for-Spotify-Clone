🎵 Spotify Web Player Clone

A Spotify-inspired web music player UI built with HTML, CSS, and Font Awesome.
This project replicates the Spotify Web Player interface with sidebar navigation, library section, trending playlists, and a bottom music player.

🚀 Features
🎨 Modern Spotify-like UI with dark theme.
📂 Sidebar navigation with Home, Search, and Your Library.
🎧 Music cards for Recently Played, Trending, and Featured Charts.
📌 Sticky top navigation bar with user actions.
🎼 Music player controls (Play, Pause, Forward, Backward, Volume).
📱 Responsive design for different screen sizes.
🛠️ Tech Stack

HTML5 – Page structure.
CSS3 – Styling & layout (Flexbox).
Font Awesome – Icons for navigation and controls.
Google Fonts – Poppins & Montserrat.
